HELP INDIA — COCKROACH PEOPLE
Founder: A.J Abdul Ansari
Package: PWA-ready web app prototype (Version 2)

WHAT'S NEW
- PWA manifest and app icon
- Service worker for basic offline caching after first visit
- Designed for mobile screens
- Existing demo sections: Community, Rules, Voting demo, Help People, Report Problem, Know Your Rights, Profile

IMPORTANT LIMITATIONS
- This is NOT an APK and is not yet published online.
- For install prompt/offline cache, the files must be hosted on an HTTPS website (localhost also works for development).
- Phone-number OTP login, online database, real member voting, admin moderation and real report delivery are NOT connected.
- Form entries are stored locally in that browser/device only. Do not enter private or sensitive information.
- Community rules must follow applicable Indian law; this app does not create a separate legal authority.

EASIEST NEXT STEP ON ANDROID
1. Keep this ZIP and extract it using your phone's Files app.
2. To make it installable, the folder must be uploaded to an HTTPS static host such as GitHub Pages.
3. Once a public HTTPS site is available, open it in Chrome on Android.
4. Chrome menu (⋮) > "Install app" or "Add to Home screen" (wording varies).
5. For real phone login and shared community data, a secure backend and privacy setup must be built separately.

NOTE
Opening index.html directly as a file is useful for previewing, but service workers and PWA installation generally require HTTPS hosting.
